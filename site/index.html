Hand-offs

It knows when to stop.

When a teammate hits something only you should do, it parks and tells you why — in the conversation and right inside its computer. You do the step; one click hands it back.

  • Sending, posting, buying, paying and deleting wait for your OK
  • Unless your request already said to do it
  • Destructive shell commands are refused in every mode

Saved logins

Your passwords never reach the AI.

Save a login once. When a teammate needs it, you get a request — Allow once, Always for this site, or Deny. MyBot types the password into the page itself, and only on the site it was saved for.

Skills

Teach it once.

Do a task yourself in its browser and it becomes a skill it can repeat — passwords and codes are never recorded. 245 skills come built in, and skills in the Agent Skills format (SKILL.md) import and export.

Routines

On a schedule.

Every morning at 8, weekdays at 9, the first of the month — or any cron expression. A teammate runs the skill and leaves the result in its conversation.

Your models

Bring Claude, GPT or Gemini.

Keys stay on your computer, encrypted with your passphrase. For GPT, use an API key — or sign in with your ChatGPT account and run on your plan.

ChatGPT sign-in runs the open-source openai-oauth helper and needs Node.js.

Updates itself — and checks first.

Every release is signed. MyBot checks the signature against its built-in key, and the download against the signed checksum, before it installs anything. Then it's one click: Restart.

Opening it the first time

These builds aren't signed by Apple or Microsoft yet, so your system warns you once.

Mac

Unpack and move MyBot.app to Applications. Right-click it, choose Open, then Open again. If macOS still refuses, run xattr -dr com.apple.quarantine /Applications/MyBot.app.

Windows

Unzip and run mybot2.exe. If SmartScreen says “Windows protected your PC”, click More info → Run anyway.

Linux

Unpack and run ./mybot2. The window needs X11 or Wayland; on Debian/Ubuntu: sudo apt install libxkbcommon-x11-0 libgl1 libegl1.
