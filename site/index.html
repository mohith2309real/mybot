Opening it the first time

These builds aren't signed by Apple or Microsoft yet, so your system warns you once.

Mac

Unpack and move MyBot.app to Applications. Right-click it, choose Open, then Open again. If macOS still refuses, run xattr -dr com.apple.quarantine /Applications/MyBot.app.

Windows

Unzip and run mybot2.exe. If SmartScreen says “Windows protected your PC”, click More info → Run anyway.

Linux

Unpack and run ./mybot2. The window needs X11 or Wayland; on Debian/Ubuntu: sudo apt install libxkbcommon-x11-0 libgl1 libegl1.
